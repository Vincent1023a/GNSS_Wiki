# 高樓遮蔽、多路徑與電離層

**遮蔽**發生在建物擋住直接訊號的時候。可用衛星可能變少，剩下的觀測幾何也可能變差。**多路徑**發生在訊號經牆面或其他表面反射後到達接收機，令碼延遲的估計偏移。直接路徑被遮蔽時也可能以反射路徑為主。[GNSS-03](../sources/GNSS-03.md) [GNSS-08](../sources/GNSS-08.md)

**電離層**也會改變碼訊號傳播時間，且延遲與訊號頻率有關。這是傳播介質的作用。高樓情境還要考慮手機融合其他來源後的定位結果。因此，看到藍點偏移，可討論這些可能因素，無法從一張畫面確定是哪一項誤差引起。[GNSS-03](../sources/GNSS-03.md) [GNSS-06](../sources/GNSS-06.md) [GNSS-07](../sources/GNSS-07.md) [GNSS-08](../sources/GNSS-08.md)
