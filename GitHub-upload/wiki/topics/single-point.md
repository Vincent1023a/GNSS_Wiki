# 單點定位與四個未知數

基本的單系統、同一時刻、未給定接收機鐘差的三維碼定位，要解接收機的地固直角坐標 $(X,Y,Z)$ 和接收機相對系統時標的鐘差 $\delta t_r$。也可用公尺表示第四個未知數 $b = c\,\delta t_r$。[GNSS-04](../sources/GNSS-04.md)

每顆已知位置的衛星提供一條[虛擬距離](pseudorange.md)約束。基本解算通常至少需要四顆衛星，並且觀測幾何需能獨立約束這四個未知數。每顆衛星的方程都含三維幾何距離和同一個接收機鐘差，因此四個量是一起估計的。[GNSS-02](../sources/GNSS-02.md) [GNSS-04](../sources/GNSS-04.md)

在較多可用衛星時，接收機可用更多觀測聯合估計。已知時間或高度的特殊解算，以及跨系統可能引入的額外時差，超出此入門模型。[GNSS-04](../sources/GNSS-04.md)
