# RTK（即時動態定位）

測量時取得參考資料，在現場解算位置。

RTK 是 Real-Time Kinematic。移動站接收衛星訊號，同時透過無線電或網路取得基準站或基準站網路的資料，據以在外業期間解算坐標。測量人員因此能在現場讀取當下位置、檢查量測狀態，或依已知坐標在現場找到放樣點。

例如工程人員需要當場標出道路邊線的設計點，且有合適的衛星觀測環境與穩定的改正資料連線，可以優先評估 RTK。建物遮蔽、訊號反射與改正資料中斷都可能影響解算。設備若可同步記錄所需觀測，有機會用 [PPK](ppk.md) 補作後處理。
