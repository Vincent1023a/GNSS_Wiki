# 二維測距圓與共用鐘差

教學示例把三顆衛星放在同一個平面，固定其位置。每顆衛星當圓心，距離當半徑。先忽略衛星鐘差、傳播延遲、雜訊等因素，零鐘差時，三個距離圓通過同一個接收機示例點。[GNSS-03](../sources/GNSS-03.md) [GNSS-04](../sources/GNSS-04.md)

把接收機鐘差換成距離偏移 $b$，可寫出簡化觀測式：

$$
b = c\,\delta t_r,\qquad P_i = \rho_i + b
$$

把 $b$ 切換成 $+1.2$ 示意單位，每個圓都增加同樣的半徑，圓心與實際接收機位置維持固定。共同的時間偏差會在每筆觀測量留下共同的距離偏差。[GNSS-03](../sources/GNSS-03.md) [GNSS-04](../sources/GNSS-04.md)

這是理想二維幾何和人造數值，用來觀察量測如何變化。實際定位以三維[單點定位方程](single-point.md)解算。
