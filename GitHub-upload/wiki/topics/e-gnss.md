# 台灣 e-GNSS

國土測繪中心提供的衛星定位服務，可作為網路 RTK 的台灣例子。

以虛擬基準站即時動態定位（VBS-RTK）服務為例，系統根據使用者的大致位置回傳虛擬基準站的觀測資料，移動站再利用這些資料解算測點坐標。可用這個例子理解 [RTK](rtk.md) 的參考資料也能來自一個基準站網路。

服務設定、申請、費用、坐標系統與適用條件請查閱[國土測繪中心 e-GNSS 入口](https://egnss.nlsc.gov.tw/)。
