# GNSS（全球導航衛星系統）

提供定位、導航和授時的衛星系統總稱。

手機地圖上的藍點是位置估計。衛星定位是手機取得位置的一種方式，手機也可能整合其他定位資訊。以 GPS 為例，衛星廣播時間和位置資訊，接收機比較多顆衛星的訊號，估算自己的位置與時間。

GPS 是 GNSS 的一套系統。Galileo、北斗和 GLONASS 也是。做外業時，接收機還可以用更細緻的觀測資料，配合參考資料來算位置。入門可從 [RTK](rtk.md) 與 [PPK](ppk.md) 開始。
