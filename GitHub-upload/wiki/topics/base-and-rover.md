# 基準站與移動站

一端提供參考，另一端在待測位置蒐集資料。

**基準站（base station）** 在已知坐標的位置接收衛星訊號，提供參考觀測資料。外業可自設本地基準站，也可用合適的既有基準站資料或服務。

**移動站（rover）** 是外業帶到待測位置的接收機。量道路邊線時，測量人員可以拿著測桿走到各待測點，架穩後記錄。移動站可以停在點上量測。

在 [RTK](rtk.md) 裡，移動站在外業期間取得參考資料。在 [PPK](ppk.md) 裡，外業通常先記錄移動站的原始觀測，之後再搭配同時段的參考觀測。
