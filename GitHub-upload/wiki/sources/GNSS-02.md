# GNSS-02 GPS and Galileo Satellite Coordinates Computation

廣播星曆提供軌道參數與參考時刻。將訊號發射時的系統時刻帶入，得到對應的衛星地固位置。

## 適用範圍

在星曆有效期間使用。學習頁省略通用的實作修正，例如為接收時刻統一地固框架所做的地球自轉處理。
