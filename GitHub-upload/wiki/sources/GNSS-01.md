# GNSS-01 GPS Navigation Message

導航電文含廣播星曆、衛星鐘差參數、健康狀態和其他資料。星曆用於算單顆衛星位置，曆書用較粗略的資訊協助搜尋衛星。

## 適用範圍

課程使用 GPS 電文共同概念。不同訊號的訊息格式各異。
