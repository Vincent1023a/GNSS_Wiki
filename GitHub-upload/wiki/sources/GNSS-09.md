# GNSS-09 GAMIT/GLOBK 2.1 Phase and Pseudorange Observations

同一顆衛星、兩個地面站的同步觀測可做站間一次差。共用的衛星時鐘項抵消，接收機鐘差仍需留在單差模型。

## 適用範圍

資料兼談載波與碼觀測。短基線相關性受大氣狀況與時空差異影響。
