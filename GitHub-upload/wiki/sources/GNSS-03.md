# GNSS-03 GNSS Basic Observables

碼觀測把接收機與衛星時鐘標記的時間差換成距離。方程包含幾何距離、兩端鐘差、電離層與對流層、儀器延遲、多路徑與雜訊。

## 適用範圍

這裡使用以公尺表示的碼觀測。不同頻率的電離層項不同，載波相位的符號與額外項也不同。

## 原文定位
