# GNSS-04 Code Based Positioning (SPS)

單系統碼定位以每顆衛星的虛擬距離作一條觀測方程，解三個接收機坐標和一個接收機鐘差。超過四筆時可組成超定系統。

## 適用範圍

假定同一時刻、一個系統時標、衛星位置已知且觀測幾何足以約束未知數。
