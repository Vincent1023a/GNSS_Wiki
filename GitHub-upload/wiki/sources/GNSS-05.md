# GNSS-05 Ellipsoidal and Cartesian Coordinates Conversion

同一點可用 ECEF 的三個笛卡兒坐標或參考橢球的緯度、經度與橢球高表示。經度由 X、Y 取向，緯度與高度須使用橢球模型。

## 適用範圍

搭配與 ECEF 參考框架相容的橢球。橢球高有自己的參考面。
